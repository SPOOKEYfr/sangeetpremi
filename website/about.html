About

Built by one developer, in the open

SangeetPremi is created and developed by SPOOKEYfr and published as open source under the GPL-3.0 license.

Source code, architecture notes, test results and an honest status ledger live in the official repository: github.com/SPOOKEYfr/sangeetpremi ↗

SangeetPremi is a browser extension for Chromium-based browsers (Chrome, Brave, Edge). It uses only the official YouTube Data API v3 for metadata; it never scrapes YouTube, never extracts audio, and playback always happens on YouTube itself. Your library, playlists and settings are stored only in your browser's local extension storage.

The optional "Create on YouTube" feature uses Google OAuth solely to publish a playlist you explicitly request to your own YouTube account. Connecting a Google account is never required for discovery or playback.

Current development status (honest):

The extension is in active development. There is no Chrome Web Store listing and no published release yet — see the Download page. A local development backend exists in the repo but is not deployed anywhere.
