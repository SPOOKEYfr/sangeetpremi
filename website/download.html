Install from source (developers) — works today

This is the real, current installation path and matches the actual package. Requires Node.js 18+ and a Chromium-based browser (Chrome, Brave, Edge).

git clone https://github.com/SPOOKEYfr/sangeetpremi.git
cd sangeetpremi
npm install
npm run build        # builds the loadable extension into dist/
  1. Open chrome://extensions in Chrome, Brave or Edge.
  2. Enable Developer mode (toggle at the top right).
  3. Click Load unpacked and select the project's dist/ folder.
  4. Click the SangeetPremi toolbar icon to open the popup; the full dashboard is available from the extension's options page.

Live discovery uses the official YouTube Data API v3. See the repository's docs/SETUP_YOUTUBE_API.md for how a developer key is configured on-device — regular users of a future store release will not need any of this.
