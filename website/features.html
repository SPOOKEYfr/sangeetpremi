Features

What SangeetPremi actually does

Everything below ships in the extension's current codebase. Nothing here is aspirational marketing copy.

◎

Artist discovery engine

Disambiguation when names collide, relevance scoring, 14 categories, and role detection — primary, featured, playback singer and more.

✓

Smart duplicate detection

Strict, balanced or off. Duplicates are collapsed but always reviewable and restorable.

☰

Playlist builder

Select, sort (5 modes), save, duplicate, export as JSON, play on YouTube, or — with your explicit optional OAuth consent — create a real playlist on your YouTube account.

❖

Multi-artist discovery

Comma-separated artists merged into one collection with per-track attribution preserved; only shared recordings ever collapse across artists.

⌕

Smart filters

Category filter, language filter (script-verified for non-Latin scripts, labelled "est." for Latin heuristics), and a release-year range verified from each video's publish date. Undated tracks are excluded, never guessed.

⟳

Incremental refresh

Re-run discovery for an artist: new tracks are shown for your review and merged only when you approve; existing playlists are never auto-modified.

⚖

Artist comparison

Side-by-side stats with verified counts clearly separated from estimates. Genre is explicitly not estimated.

✥

Drag-and-drop playlists

Reorder with drop indicators, keyboard-accessible move buttons, bulk select/remove, per-playlist search and selection statistics.

▣

Persistent local library

Saved artists, discovery history and favorites live only in your browser's local storage — exportable as JSON, erasable in one click.

◈

Claymorphism UI

A premium dark design across the popup, side panel and full dashboard.

⛨

Official API only

YouTube access goes exclusively through the official YouTube Data API v3 with on-device quota tracking. No scraping, no undocumented endpoints, no audio extraction. Playback always happens on YouTube itself.

⛨

Optional local backend

A zero-dependency Node.js companion API exists for development (local only, not deployed). Normal extension use does not require it.

Not claimed:

No user counts, no testimonials, no "compliant with YouTube policy" certification (policy interpretation is documented in the repo, not certified here), and no production backend — the public service is the extension itself.
